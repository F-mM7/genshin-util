# 原神 天賦・武器秘境IVの素材ドロップ確率(推定)

公式の確率は非公表。以下は有志の解析・実測にもとづく推定モデルで、「実測」とは区別して載せる。

## 仕組み

出典: 英語版 Fandom wiki「Loot System / Material Drop Distribution」(有志の説明)。

- 1周(天然樹脂20)の報酬 = (a) **固定部分**(最下位素材のみ、個数を抽選) + (b) **変動部分**(枠数を抽選し、枠ごとにレアリティを抽選)。
- ドロップ表の本体はサーバー側にあり、クライアントの `RewardPreviewExcelConfigData` には固定部分の平均値しかない。

| 秘境 | 固定平均 | 枠数平均 | 枠のレアリティ |
|---|---|---|---|
| 天賦IV | 教え 2.2 | 2.2 | 導き90% / 哲学10% |
| 武器IV | ☆2 2.2 | 3.1 | ☆3 78% / ☆4 20% / ☆5 2% |

**前提(推定)**: 固定部分と枠数は平均に合う隣り合った2整数をとり(例: 平均2.2なら2個80%/3個20%)、各枠は独立に抽選されるとした。数値は Python スクリプトの計算出力。

## 天賦IV

固定 教え2個80%/3個20% + 枠2個80%/3個20%、各枠 導き90%/哲学10%。

| 個数 | 教え | 導き | 哲学 |
|---|---|---|---|
| 0 | - | 0.8% | 79.4% |
| 1 | - | 14.9% | 19.3% |
| 2 | 80.0% | 69.7% | 1.3% |
| 3 | 20.0% | 14.6% | 0.0% |
| 期待値 | 2.200 | 1.980 | 0.220 |

- 哲学が1個以上出る確率: 20.6%
- 濃縮樹脂1回(=3周分)あたりの哲学: 0個 50.0% / 1個 36.4% / 2個 11.4% / 3個 2.0% / 4個 0.2%(平均 0.660)

## 武器IV

固定 ☆2 2個80%/3個20% + 枠【仮定】2個10%/3個70%/4個20%、各枠 ☆3 78%/☆4 20%/☆5 2%。枠数は平均3.1しか分かっておらず分布が一意に決まらないため、実測の合計個数(4〜7個)に合う分布を1つ**仮定**した。

| 個数 | ☆2 | ☆3 | ☆4 | ☆5 |
|---|---|---|---|---|
| 0 | - | 1.3% | 50.4% | 93.9% |
| 1 | - | 12.0% | 38.3% | 5.9% |
| 2 | 80.0% | 37.7% | 10.2% | 0.1% |
| 3 | 20.0% | 41.6% | 1.1% | 0.0% |
| 4 | - | 7.4% | 0.0% | 0.0% |
| 期待値 | 2.200 | 2.418 | 0.620 | 0.062 |

- ☆5が1個以上: 6.07% / ☆4が1個以上: 49.6%
- 期待値は枠数分布の形によらず平均3.1だけで決まる。

## 実測との比較

- **Genshin Data Gathering**(1周平均): 天賦IV 教え2.20・導き1.97・哲学0.23(n=7,392)、武器IV ☆2 2.20・☆3 2.40・☆4 0.64・☆5 0.07(n=5,850)。いずれもモデルの期待値とほぼ一致。
- **米游社の個人記録**(天賦IV、濃縮樹脂の旧仕様=1回2周分、264回): 哲学 0個 169 / 1個 83 / 2個 10 / 3個 2(平均0.413)。モデル(0.440)とのカイ二乗値は1.54(3区分、自由度2)で矛盾しない。

## 樹脂・イベント

- Ver6.0(Luna I)以降、濃縮樹脂は天然樹脂60で作成し1回で3周分を受け取る。天然樹脂40で2周分の選択肢もある(米游社 post 68360721)。
- 2倍イベント「豊材の奔流」は天然樹脂のみ対象、1日3回まで。

## 注意点(未検証)

- 確率はどれも公式値ではなく、wiki の値も有志の推定。
- 「隣り合った2整数」の形と武器IVの枠数分布は、この文書で置いた仮定。
- 濃縮樹脂等の複数周分が1周ずつ独立に抽選されるかは公式未明言(wiki とプレイヤー証言のみ)。計算は独立と仮定。
