# 原神ユーティリティ

原神まわりの計算をブラウザで行うためのツール集です。

公開URL: **https://F-mM7.github.io/genshin-util/**

## できること

5 つの機能を切り替えて使えます。入力した値は自動で保存され、次回開いたときも続きから使えます。

### 樹脂キャパ

「次に原神を開く時刻」までに樹脂がどれだけ回復し、保有上限（200）からどれだけあふれるかを計算します。

- 入力: アクセス予定日時／現在樹脂／濃縮樹脂／消費予定
- 「次の 5 時」「次の水曜 5 時」などのワンクリックプリセット
- 結果: 残り時間、回復量、キャパ余裕、あふれ、可処分樹脂

### 天賦素材

複数キャラ分の「天賦現在 Lv → 目標 Lv」に必要な ★2 / ★3 / ★4 天賦本の総数を計算し、所持数で足りる「充足確率」を周回数ごとのグラフで表示します。

- 入力: 天賦行（現在 Lv／目標 Lv／個数）、★2 〜 ★4 の所持数、周回数上限（1 〜 40）
- 行の追加・削除でキャラ数を可変
- 天賦秘境 IV を 0 回から周回数上限まで周回した場合の充足確率を折れ線グラフで表示（ドロップ率の根拠: [docs/domain-drop-rates.md](docs/domain-drop-rates.md)）

### 武器突破素材

武器のレアリティと現在突破段階から、所持数で次の各突破段階に到達できる「充足確率」を周回数ごとのグラフで表示します。

- 入力: クオリティ（★3 / ★4 / ★5 武器）、現在突破、周回数上限（1 〜 40）、★2 〜 ★5 の所持数
- 「強化」ボタンで次の突破に必要な素材を所持数から差し引き、現在突破を 1 段階進める
- 1 つ下のレアリティの素材 3 個を消費して 1 個／2 個に合成するボタン
- 武器秘境 IV を 0 回から周回数上限まで周回した場合の充足確率を、目標突破段階（現在突破 + 1 〜 6）ごとの折れ線グラフで表示（ドロップ率の根拠: [docs/domain-drop-rates.md](docs/domain-drop-rates.md)）

### ダメージ計算

ステータスとバフから評価値・会心バランス・杯トレードオフを計算します。

- 入力: 計算対象ステータス、各種ステータス値、任意のバフカード
- 結果: 評価値、会心率と会心ダメージのバランス、杯選択のトレードオフ

### 聖遺物経験値

現在 Lv → 目標 Lv に必要な聖遺物経験値素材を最小コストで算出します。

- 入力: レアリティ、現在 Lv ／経験値、選択サブステとその値、利用可能な強化素材
- 結果: 必要経験値、素材プラン、強化シミュレーション
- ★5 では強化目標の聖遺物を複数登録して合算プランニング可能
